# AGENTS.md

Instructions for any AI coding agent working in this repo (Claude, Codex, Cursor, Copilot, or others).

## Read first

1. **`CLAUDE.md`**: the project rules (tech stack, coding standards, how to work). Follow it even if you are not Claude.
2. **`design/game-brief.md`**: the design source of truth for Emberhollow. Read it before any task. If a request conflicts with it or it is unclear, stop and ask Marcel.

## After each working step

1. Run the project headless (or the test scene) and fix every error and warning.
2. Update **`docs/STATE.md`**: what exists, what's next, known issues. Anyone should be able to pick up from it.
3. Commit to Git with a clear Conventional Commits message (`feat:`, `fix:`, `docs:`, and so on).

## When done

Push your commits to the remote.
